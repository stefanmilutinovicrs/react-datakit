# react-datakit

Headless, accessible React components for data-heavy B2B apps: admin panels, dashboards and ERP systems.

The [README](https://github.com/stefanmilutinovicrs/react-datakit#components) lists every component and its status.

## Principles

- **Headless core + hook.** Every component is a hook (`useCombobox`) plus compound components built on it.
- **Controlled or uncontrolled.** Every value works with `value` + `onChange` or `defaultValue`.
- **WAI-ARIA Authoring Practices.** Roles, `aria-*` attributes and keyboard behavior follow the official patterns.
- **Style with anything.** State is exposed as data attributes (`data-state`, `data-highlighted`, `data-selected`).
- **Optional theme.** `import 'react-datakit/styles.css'` and change `--dk-accent`; your CSS always wins.
